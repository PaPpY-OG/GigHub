GigHub

A freelance marketplace web application built with Django where clients can post gigs and freelancers can bid on projects.

Features
- Client & Freelancer authentication
- Post and manage gigs
- Submit bids
- Accept/reject bids
- Orders management
- Real-time messaging system
- Reviews and ratings
- Profile management

Tech Stack
- Python
- Django
- HTML
- CSS
- SQLite
